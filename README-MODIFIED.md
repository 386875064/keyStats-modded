## 二、为什么改

我是一个普通用户，日常用 KeyStats 记录自己的键鼠数据。玩《英雄联盟》的时候发现一个问题：
**它统计不到游戏里的操作。**

翻了自己的历史数据后发现是这么回事（205 天的记录）：

| 进程 | 记录情况 |
|---|---|
| `LeagueClientUx`（游戏客户端） | 每天有 1~15 次点击被记录 —— 正常 |
| `League of Legends`（游戏本体） | **按键数恒为 0**，只有零星 1~6 次点击 |

也就是说：进了对局之后，键盘钩子基本收不到任何事件。

查下来的原因是——游戏进程（国服是 TP / ACE 反作弊）在运行期间会摘除第三方的全局低级钩子
（`SetWindowsHookEx`），这在游戏反作弊里是很常见的做法。所以这不是"没识别到游戏"，而是"钩子被拆了"。

既然上游短期不会处理，就想着自己补一个能用的版本。

## 三、改了什么

只改了 Windows（.NET Framework 4.8 + WPF）部分。**macOS（Swift）代码一行都没动。**

### 3.1 游戏对局统计（核心）

| 改动 | 说明 |
|---|---|
| 自动对局识别 | 检测到 `League of Legends.exe` 启动即自动开局，进程退出 3 秒后结算落盘 |
| **双采集通道** | 新增 Raw Input 通道（`RegisterRawInputDevices` + `RIDEV_INPUTSINK`）作为主通道，原低级钩子降级为兜底。Raw Input 是系统直接投递到程序窗口的，不注入、不挂钩子，反作弊摘不到 |
| 通道仲裁 | 同一时刻只用一条通道计数，不会重复；主通道在 20 秒宽限期内收不到任何事件则自动切到钩子 |
| 对局指标 | 时长、按键数、五类鼠标点击、鼠标移动距离、滚轮、实时 APM（60 秒滚动窗）、平均 APM、峰值 KPM/CPM/APM、峰值 KPS、本局按键分布 |
| 游戏内 HUD | 游戏进行中自动出现的置顶小浮窗（时长 \| APM \| 按键 \| 点击），可拖动、可锁定 |
| 对局详情 | 双击历史里的一局查看：每分钟操作时间轴柱状图 + 本局键盘热力图 |
| 采集状态自检 | 显示当前用的是哪条通道、钩子被重建过几次、本局是否零输入 —— 便于排查"为什么统计不到" |

### 3.2 使用洞察（日常功能）

上游只管"今天按了多少键"。我加了几个自己想知道的东西：

- **打字质量**：退格率（Backspace 占总按键的比例）、修饰键（Ctrl/Shift/Alt/Win）使用量
- **专注度**：应用切换次数、最长连续专注时长（哪个应用连续占了多久）
- **作息节奏**：当前连续使用时长、今日最长连续使用、今日活跃总时长
- **活跃时段分布**：24 小时柱状图
- **前台时间最长的应用** Top 8
- **久坐提醒**：连续使用超过设定时长（默认 90 分钟，可调）弹通知提醒活动

### 3.3 离线化与隐私

上游默认会做一些匿名使用数据上报（分析服务 key 是硬编码的，指向原作者的分析账号）。
我不需要联网功能，所以：

- **云端同步**：UI 入口已移除，程序启动时也不再启动同步服务（同步相关的类仍保留在源码树里，但永远不会被创建）
- **分析上报**：客户端不再创建，默认关闭；并加入一次性迁移，会把从上游配置里继承下来的 key 自动清除
- **CI**：删除了 4 个指向上游 Cloudflare 基础设施的 workflow

实测：程序运行期间，该进程**没有任何 TCP/UDP 连接，也没有监听端口**。

### 3.4 数据关系（改动前请先看这张表）

| 数据层 | 文件 | 游戏期间是否计数 |
|---|---|---|
| 使用洞察（工作活跃） | `insights.json` | 不计数（游戏不算"工作"） |
| 每日总量 / 分应用 | `daily_stats.json` | 计数 |
| 对局记录（明细） | `game_sessions.json` | 计数（独立） |

游戏里的操作默认**同时计入**每日总量（否则"今天敲了多少键"会缺一大块）；
对局记录本身始终独立。任何时刻只有一条计数路径，不会重复计数。
不想让游戏数据进总量的话，在「游戏统计」窗口的选项里可以关掉。

### 3.5 其他零碎

- 应用统计里 `League of Legends` 显示为「英雄联盟」
- 新增 `KEYSTATS_DATA_DIR` 环境变量，可把数据目录搬到别处（便携/多开用）
- 补充了中英文本地化字符串

## 五、怎么用

1. 退出正在运行的官方版 KeyStats（托盘图标右键 → 退出）
2. 从 [Releases](../../releases) 下载 `KeyStats-Windows-*.zip`，解压到固定目录
3. 双击 `KeyStats.exe`

入口：

- 托盘图标右键 → **游戏统计**（对局列表，双击某局看时间轴与热力图）
- 托盘图标右键 → **使用洞察**（打字质量 / 专注度 / 时段分布）
- 托盘图标右键 → **游戏内 HUD**（游戏里的小浮窗，默认开）
- 托盘图标左键 → 主面板

**如果游戏里统计不到**，先看「游戏统计」窗口顶部的「采集状态」，它会直接告诉你用的哪条通道、
钩子被重建过几次。详细排查步骤见 `KeyStats.Windows/dist/*/README-GameStats.txt`。

## 六、怎么自己编译（Windows）

需要 .NET SDK（8.0 即可，.NET Framework 4.8 是 Windows 自带的运行时）：

```bash
cd KeyStats.Windows
dotnet build KeyStats/KeyStats.csproj -c Release -o dist/KeyStats
```

产出的 `dist/KeyStats/KeyStats.exe` 可直接运行。macOS 部分我没动，也不清楚怎么构建。

## 七、已知问题

- 独占全屏（Exclusive Fullscreen）下 HUD 浮窗不显示 —— 这是 Windows 的限制，任何置顶窗口都一样；统计本身不受影响。想看 HUD 就把游戏设成「无边框窗口」
- 游戏列表目前写死为《英雄联盟》。想加别的游戏，需要改 `Services/GameProfile.cs` 里的进程名
- 如果连 Raw Input 都被反作弊拦（极少见），那就没辙了
- 上游的 Cloudflare Workers 同步服务本仓库不包含、不启动
